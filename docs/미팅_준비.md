# 건축학과 교수님(김주형) 미팅 준비 — 컨펌 + 자문

> 목적: 방향 컨펌 + 구조·ML 관점 자문. 핵심 프레임 = **"저비용 시설물 안전 트리아지(선별)"**.

---

## ★ 첫 미팅 실전 순서 (교수님은 우리 프로젝트를 처음 봄 — 이것만 봐도 됨)

**STEP 1 — 30초 정의**
> "**스마트폰 사진으로 노후·소규모 건물을 1차 선별**해, 정밀진단이 필요한 곳(불량)만 골라내는 저비용 도구입니다. **붕괴 예측이 아니라 선별**이에요."

**STEP 2 — 왜/어떻게 (2분, 핵심만)**
- 문제: 노후 소규모 건물은 정밀진단이 비싸 방치됨 → 저비용 1차 선별 필요
- 방법: 사진 → AI 2개(**균열 위치 탐지** + **등급 분류**) → 우수/보통/불량 → **불량만 정밀진단으로**
- 데이터: 서울시 공공데이터의 **전문가 라벨을 학습**(등급 기준을 우리가 임의로 안 만듦)
- 실증: 등급 정확도 **75%**, 위험 건물 놓침 **12%**

**STEP 3 — 앱 30초 시연**
불량 사진 → **D·정밀진단 필요** / 우수 → 관리 / 대시보드 → **선별 절감** (http://localhost:5173, 시연사진 `demo_samples/`)

**STEP 4 — 솔직한 한계 먼저 (신뢰 확보의 핵심)**
1. 등급은 **분류가 결정**, 탐지 박스는 시각화용(약함)
2. 균열 **폭은 미측정**
3. 정확도에 **데이터 누수(45%)** → 재검증 중
4. **순수 데이터 기반**(역학 미결합)

**STEP 5 — 핵심 질문 4개만 (우선순위)**
1. ⭐ **균열 방향·위치로 파괴모드(전단/휨) 구분**해 위험 선별에 넣는 게 유효한가요? *(교수님 정중앙, 최대 발전방향)*
2. ⭐ **순수 CNN에 역학 지식을 어떻게 결합**하나요? *(mechanics-informed)*
3. **위험한 균열 폭이 몇 mm**부터인가요? 폭 외에 뭘 봐야 하나요?
4. 구조·ML 전문가 눈에 **가장 큰 허점**은 무엇인가요?

> 세부(법령·데이터 구조·균열폭 시나리오 등)는 물어보면 아래 상세·부록에서 꺼내면 됨.

### 미니 용어집 (설명하다 나오면)
- **CNN**: 이미지를 보고 패턴을 학습하는 AI. 우리 탐지·분류 모델 둘 다 CNN.
- **순수 CNN**: 사진+정답만 보고 학습(역학 지식 없음) → black-box, 처음 보는 상황에 약함.
- **mechanics-informed ML**: CNN에 역학 지식·제약을 결합해 신뢰성↑ (교수님 전문). 예) RC 전단강도 예측.
- **RC 전단강도**: 철근콘크리트가 '어긋나게 자르는 힘(전단)'에 버티는 한계. 전단 파괴는 **경고 없이 갑자기(취성)** → 매우 위험. **대각선 균열**이 그 신호.
- **탐지 vs 분류**: 탐지=균열 위치(박스), 분류=등급 판정. **등급은 분류가 결정.**
- **균열 폭(현황)**: 현재 **미측정**. 세그멘테이션으로 픽셀 폭은 가능, mm는 마커/스케일 필요.
- **데이터 누수(leakage)**: 같은 촬영의 연속 프레임이 학습·검증 양쪽에 들어가 정확도가 부풀려진 문제(45%).

## 0. 교수님 프로필 & 전략 (먼저 읽기)

- **전문**: 철근콘크리트(RC)·내진설계·**physics/mechanics-informed machine learning** (구조공학에 ML을 역학과 결합). 관련 논문: *mechanics-informed ML로 RC 보 전단강도 예측*, *mechanics-based ML로 내력벽 파괴 분류*, *PINN*.
- **의미**: 우리한테 **최고의 자문자이자 가장 날카로운 비평가.** 우리 접근(순수 데이터 CNN)의 약점을 정확히 볼 사람.
- **전략**:
  1. 순수 데이터 기반의 **black-box 약점을 먼저 인정** → 방어 말고 **자문으로 전환** (교수님을 본인 전문성으로 끌어들임).
  2. **정확도 실증의 leakage 문제도 먼저 공개** (이 교수님은 검증을 논문에서 늘 함 → 선제 공개가 최고의 신뢰 신호).
  3. 자문의 금맥 = **mechanics-informed 방향**(§7-B), 특히 **균열 패턴→파괴모드**.

## 4. AI 작동 원리 (서비스에 어떻게 끼워넣나)

```
[폰] 촬영·업로드 → [서버] 이미지 수신
   ├─ 모델① 탐지(YOLO)     → 균열이 "어디" (박스)
   └─ 모델② 분류(YOLO-cls) → "얼마나 심한가" (우수/보통/불량 확률)
        → [후처리] 등급 A/C/D + 정밀진단 여부 → [앱] 표시·대시보드
```
- **학습(코랩 A100, 1회)** 과 **추론(서버, 매 요청)** 분리. 학습 결과 = 가중치 파일 `best.pt`·`grade_cls.pt`.
- 서버가 그 파일을 로드해 이미지에 적용 = "AI를 끼워넣는다". 파일 없으면 자동 폴백.
- CNN 원리: 필터로 가장자리·질감 → 층 깊어지며 "균열 패턴" 인식 → 탐지는 박스+확률, 분류는 등급 확률 출력.
- **한 줄**: "코랩에서 학습한 두 CNN을 가중치 파일로 서버에 탑재 → 추론으로 위치·등급 산출 → 안전등급·트리아지 규칙을 얹어 앱에 표시."

## 5. 정확도 실증 (+ 정직한 약점)

**분류 모델 (검증셋 1,629장, hold-out) 혼동행렬:**
```
실제\예측   우수  보통  불량
  우수      262   15   35
  보통       39  180  204
  불량       35   74  785
```
| 지표 | 휴리스틱(탐지+규칙) | **분류 모델** |
|---|---|---|
| 등급 정확도 | 22.3% | **75.3%** |
| 불량 재현율 | 21.9% | **87.8%** |
| 위험 누락률 | 78.1% | **12.2%** |

- 보통 재현율 42.6%(약점) — 대부분 불량으로 넘김(**안전한 보수적 오류**)
- 탐지 모델 mAP50 0.217 / recall 0.27 (얇은 균열 bbox의 근본 한계 — §7-A 자문)

**⚠️ 정직 공개 (반드시 먼저 말할 것):**
- 검증셋 촬영 소스의 **45%가 학습셋에도 존재**(연속 프레임 랜덤 분할로 인한 **누수, leakage**) → **75.3%는 낙관적**. 처음 보는 건물에선 더 낮을 것.
- 해결: **소스(건물) 단위 재분할 → 재검증/재학습** 진행 예정. 그게 진짜 일반화 성능.
- 이 약점을 **먼저 말하면** 이 교수님한텐 최고의 신뢰 신호.

## 6. 예상 질의응답

**Q1. 사진 한 장으로 건물 전체 안전을 판단?** → 판단 안 함. 부위별 이미지 등급을 매기고, 관리자가 모아 "정밀진단 보낼지"를 정하는 **선별 도구**. 진단은 전문가 몫.

**Q2. 안전등급 A~E 근거? 법정과 같나?** → 시설물안전법 시행령 [별표 8] A~E 체계를 **차용**(우수→A, 보통→C, 불량→D). 법정 등급 **발급 아님**, 스크리닝 지표. (부록 A)

**Q2-1. 무슨 기준으로 등급을 매기나?** → 자체 기준 아님. **공공데이터 전문가 라벨을 학습.** 데이터 분석상 등급은 결함 **종류가 아니라 심각도**로 갈림(부록 B) → 종류 휴리스틱 22% 실패, 심각도 분류 75% 성공.

**Q3. 균열 폭·방향·위치는 반영하나?** → **현재 약점.** 종류·등급 위주고 폭 정량화·방향은 미흡 → **자문 요청(§7-A).**

**Q4. 위험누락 12%면 8건 중 1건 놓친다. 괜찮나?** → 1차 필터(2차=전문 진단). 임계값을 **불량 쪽 보수적**으로 둠(애매하면 정밀진단). 누수 보정 후 재측정 예정.

**Q5. "보통" 42%로 낮은데?** → 보통↔불량 경계가 애매, 대부분 **불량으로 넘김(안전한 방향)**. 개선 과제.

**Q6. 데이터가 현장을 대표?** → 공공데이터라 라벨 신뢰는 있으나 촬영조건·유형 편중, 현장 미검증(향후 과제).

**Q7. 기존 정밀진단·드론과 차이?** → 그들은 고비용·전문가·대형시설. 저희는 스마트폰·비전문가·소규모 노후 건물 대상 **관리용 선별 도구**.

**Q8. (시그니처) 왜 물리·역학 없이 순수 데이터로만?** → 현재는 데이터 기반 스크리닝 MVP. black-box 한계 인지, **mechanics-informed가 다음 단계**. 교수님 연구가 그 지점이라 **어떻게 역학을 결합할지 자문(§7-B).** *방어 말고 자문 전환.*

**Q9. 현장 관리자는 눈으로도 아는데 왜 필요?** → 인정: 명백한 케이스는 사람도 앎. 근데 우리 사용자는 **비전문가**, 대상은 **다수 시설**, 그리고 눈은 **기록·진행성 추적·일관성**을 못 함. "신고 앱"이 아니라 **관리 도구**. 가치는 **애매한 중간 영역 + 시간에 따른 변화 추적**.

## 7. 자문받을 것 (교수님 전문성 맞춤)

### A. 균열 폭·구조적 위험
1. **위험 임계 폭** — 유의미한 균열 폭 경계? (사용성 0.3mm? 철근 부식 유발 폭? 구조 균열 폭?) 재료(RC/조적)·환경(옥외/옥내)별 차이?"현재는 균열 폭을 명시적으로 측정하지 않고, 분류 모델이 이미지 전체의 심각도로 등급을 냅니다. 폭 정량화는 다음 단계이고, 그때 쓸 위험 임계 폭 기준을 교수님께 여쭙고 싶습니다."

2. **폭만으로 충분?** — 길이·간격(밀도)·관통 여부·방향도? 폭↔위험 매핑에 무엇을 더하나?
3. **측정 위치·방법** — 최대 폭? 대표 폭? 표면 vs 관통 구분?
4. **진행성** — 자라는 균열 vs 안정 균열, 폭 하나론 부족한 지점 보완?
5. **기준물(마커) 실무성** — 현장에서 규격 마커 두고 촬영이 현실적? 대안?
6. **공식 기준 출처** — 콘크리트구조기준·시특법 세부지침의 균열 폭 평가 기준 중 인용할 것?

### B. 기계학습 — mechanics-informed (금맥)
7. **역학 결합 방법** — 순수 데이터 분류에 **역학 지식을 어떻게 결합**(feature·물리 제약·loss·구조)해 신뢰성을 높이나?
8. **균열 패턴 우선순위 → 파괴 모드** (⭐우리 최대 발전 방향, 교수님 파괴 분류 논문 직결)
   - *실제 물어볼 문장*: "AI-Hub 오픈 데이터로 비전 모델을 파인튜닝할 때, **구조 안전 위험도를 더 정확히 선별하려면 어떤 균열 패턴을 우선 학습**시켜야 할까요? 균열 패턴 간 **구조적 중요도·우선순위**가 있는지, **사진 분석 시 유의할 점**은 무엇인지 궁금합니다." 
   - 뜻: 지금은 모든 균열을 동등하게 봄 → 위험한 패턴(대각 전단·주요부재 균열)에 **학습 가중치**를 둘 근거를 얻고 싶음
   - 후속: "**비구조(마감) 균열을 위험으로 오인**하지 않으려면 학습에서 어떻게 걸러야 하나요?"
   - ⚠️ 표현 주의: "붕괴 예측" 아님 → **"구조 안전등급 선별/결함 심각도 판정"**
9. **Black-box 신뢰성** — 순수 CNN의 신뢰성·해석가능성 한계를 역학 제약으로 보완? 일반화에 도움?

## 부록 A. 안전등급 A~E 법적 근거 (원문)

**「시설물의 안전 및 유지관리에 관한 특별법 시행령」 [별표 8] (제12조 관련)**

| 등급 | 시설물의 상태 (원문) |
|---|---|
| **A (우수)** | 문제점이 없는 최상의 상태 |
| **B (양호)** | 보조부재에 경미한 결함, 기능 지장 없음, 내구성 위해 일부 보수 필요 |
| **C (보통)** | 주요부재 경미한 결함 또는 보조부재 광범위 결함, 전체 안전엔 지장 없음, 보수/간단 보강 필요 |
| **D (미흡)** | 주요부재 결함으로 긴급 보수·보강 필요, **사용제한 여부 결정** |
| **E (불량)** | 주요부재 심각한 결함, 위험, **즉각 사용금지** 및 보강·개축 |

**출처**: 국가법령정보센터 시행령 [별표 8](https://www.law.go.kr/flDownload.do?gubun=&flSeq=33110075&bylClsCd=110201) · 세부지침 [별표 2](https://www.law.go.kr/flDownload.do?flSeq=132039299&bylClsCd=200201)
**프레이밍**: 법정 등급 발급 아님 → 용어·심각도 체계 차용한 선별 신호. 매핑 우수→A/보통→C/불량→D. **E(즉각 사용금지)는 사진으로 부여 안 함**(보수적).

## 부록 B. "무슨 기준으로 등급?" — 데이터 근거

**결함 종류별 등급 비율:**
| 결함 | 우수 | 보통 | 불량 |
|---|---|---|---|
| 균열 | 12% | 12% | **76%** |
| 박리·박락 | 10% | 14% | **76%** |
| 철근노출 | 10% | 12% | **79%** |

→ 세 결함의 등급 분포가 거의 동일 = **등급은 결함 "종류"와 무관, "심각도"로 갈림.**
→ ∴ 종류 휴리스틱 22% 실패 / 시각 심각도 분류 75% 성공. 구조적으로도 타당(실금 vs 관통).
→ (전체는 불량 편중: 불량 13,112 / 보통 2,158 / 우수 1,760. 학습셋은 셀당 상한 1,500 균형 샘플)

## 부록 C. 균열 폭 정량화 — 우리 몫 / 자문 몫

**🅐 우리가 할 수 있는 것**
- 픽셀 폭 측정: 폴리곤/세그멘테이션 → 중심선(skeleton) + 거리변환으로 최대·평균 픽셀 폭
