## 1. 교수님 핵심 조언 요약

### 진단 (현재의 한계)
- 사진 한 장·균열 하나로 건물 등급 판단은 **불가능** — 건물 전체·균열 위치·분포를 봐야 함 → 그 단계는 "건너뛴다"고 인정하고, **부위 단위 신속 선별**로 명확히 포지셔닝
- 파괴 관련 균열 vs 표면 균열을 구분 못 하는 게 약점 — 구분이 진짜 가치

### 도메인 지식 (알려주신 것)
- **구조적 균열**: 전단 균열(대각선, 취성 파괴 신호) / 휨 균열(수직) / 접합부(joint) 균열(지진 시 중요)
- **위치 중요도**: 기둥 균열 ≫ 보 균열 (기둥 붕괴 = 건물 붕괴, 보 = 그 층만)
- 용어: beam(보)·column(기둥)·wall(벽)·core·joint(접합부)·RC(철근콘크리트)
- 균열 폭 기준은 시설물 안전진단 자료에 존재 → 찾아서 활용

### 모델 개선 방향 (contribution 만들기) ⭐
1. **역학 정보는 convolution하지 말고 별도 feature로** — 이미지(CNN) + 균열 폭 등 역학 데이터(별도 입력) 분리 구조
2. **Loss function에 역학 반영** — 예: 균열 폭 오차에 큰 가중치 (기준은 안전진단 자료에서)
3. 분류를 상세화 — 전단/휨 **타입 구분** + 폭 측정 → 세분 분류
4. **개선 전/후 비교가 실증의 핵심**: "순수 YOLO vs 우리가 개선한 모델" 정확 비교 → "우리 기여로 성능 향상" (전문가보다 정확 주장은 ❌)

### 출력·전처리
- **확률로 출력** (D등급일 확률 60% 등) — 불확실성을 통계로 표현, 근거 부족을 커버
- **전처리로 촬영 편차 통제**: 크롭 + 흑백 변환 + 밝기 정규화 → 어디서 찍든 동일 조건
- 사용자 촬영 지침 + agent(LLM) 설명 서비스

### 포지셔닝
- ❌ 정밀진단 → ✅ **신속 초기 선별(중간 단계)**. 전문성 대체 아님
- 대상: 일반인·노후 아파트·시공 중 검토 등 (구조 전문가 대상 아님)
- 도메인 지식 2 : 데이터 접근 8 비율로

### 자료
- Google Scholar: crack detection / crack width / damage assessment 논문 다수 → 아이디어 소스
- 현장 지인에게 실제 사진 받으면 가점

## 2. 액션 플랜 (우선순위)

| P | 작업 | 내용 | 상태 |
|---|---|---|---|
| **P0** | 누수(leakage) 수정 재분할 | 촬영 소스 단위로 train/val 재분할 → 정직한 기준선 확보 (모든 비교 실험의 전제) | 진행 |
| **P0** | 프레임·문구 정리 | "신속 초기 선별(중간 단계)" 통일, 확률 표시 강화 | |
| **P1** | **개선 실험 A: 전처리 파이프라인** | 흑백+밝기 정규화(CLAHE)+크롭 → baseline 대비 성능 비교 | |
| **P1** | **개선 실험 B: 2단계 구조** | 탐지 크롭 → 분류 (결함 부위 집중) vs 통짜 분류 비교 | |
| **P1** | **개선 실험 C: 클래스 가중 loss** | 불량 재현율 가중(안전 우선) → 위험누락률 비교 | |
| **P2** | 전단/휨 타입 구분 검토 | 라벨 없음 → 박스 종횡비/방향 근사 or 논문 기반, 실험적 | |
| **P2** | 논문 조사 | crack width, damage assessment, mechanics-informed 사례 | |
| **P3** | 현장 사진 확보 | 지인 현장 사진으로 실전 검증 | |

**발표 스토리**: "순수 YOLO-cls(baseline) → 우리의 개선(전처리+2단계+가중 loss) → 성능 향상 표" = 교수님이 말한 contribution 실증.
